# 06 · 部署与运维方案

## 1. 环境清单

| 项 | 前端 | 后端 |
| --- | --- | --- |
| 托管 | Vercel (Hobby/Pro) | 自有 Windows Server 2019/2022 |
| 域名 | `village.example.com` | `api.example.com` |
| 运行方式 | 静态构建产物 + CDN | Windows 服务（NSSM → uvicorn） |
| HTTPS | Vercel 自动 | Caddy 自动 ACME |
| 公网 IP | — | 需固定公网 IP 或 DDNS（家用宽带需确认 80/443 未被封） |
| 依赖 | Node 20+ | Python 3.12 / ffmpeg / Caddy / NSSM |

**服务器最低配置**：4 核 / 8GB 内存 / 系统盘 100GB + 数据盘 500GB（媒体存储），上行 ≥ 10Mbps。

### 2.2 `web/vercel.json`

```json
{
  "rewrites": [{ "source": "/((?!api/).*)", "destination": "/index.html" }],
  "headers": [
    {
      "source": "/assets/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }]
    },
    {
      "source": "/(.*)",
      "headers": [
        { "key": "X-Content-Type-Options", "value": "nosniff" },
        { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" },
        { "key": "X-Frame-Options", "value": "SAMEORIGIN" }
      ]
    },
    {
      "source": "/sw.js",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=0, must-revalidate" }]
    }
  ]
}
```

- SPA 回退必需，否则刷新 `/posts/123` 会 404。
- `sw.js` 必须不缓存，否则 PWA 永远拿不到新版本。

### 2.4 环境变量

在 Vercel → Settings → Environment Variables 配置（Production / Preview 分别设置）：
`VITE_API_BASE_URL`、`VITE_WS_BASE_URL`、`VITE_SITE_NAME`、`VITE_ENABLE_ANALYTICS`。

### 2.5 备案完成前的过渡部署（阶段 A/B）

域名备案 7–20 个工作日，前期不能让开发等备案。方案：**前端用平台免费域名 + 后端用 Cloudflare Tunnel**，全程不解析自有域名到大陆 IP，无需备案。

| 层 | 平台 | 地址 | 限制 |
| --- | --- | --- | --- |
| 前端主站 | Vercel（Hobby 免费） | `https://village-memory.vercel.app` | 个人非商业用途；国内访问速度一般 |
| 前端备用 | Cloudflare Pages（免费） | `https://village-memory.pages.dev` | 同上，同一构建产物可双发 |
| 后端 API | Cloudflare Tunnel（免费） | 命名隧道：`https://api-dev.<你的域名>`；快速隧道：`https://xxx.trycloudflare.com` | 单请求 ≤ 100MB；WS 空闲 100s 断 |

**Cloudflare Tunnel 安装（后端服务器上）**

> 区分两个层次：**快速隧道**（`cloudflared tunnel --url http://127.0.0.1:8000`，零配置、随机 `trycloudflare.com` 域名，重启就变，只适合开发联调）；**命名隧道**（需要把任一域名托管到 Cloudflare，可用便宜的低价域名或已有的未备案域名，地址固定，适合阶段 B 试运行）。

```powershell
# 1. 安装 cloudflared
winget install --id Cloudflare.cloudflared
cloudflared tunnel login                 # 浏览器授权
cloudflared tunnel create village-api    # 记下 Tunnel ID
cloudflared tunnel route dns village-api api-dev.<你的测试域>.xyz

# 2. 配置文件 C:\Users\village-svc\.cloudflared\config.yml
```

```yaml
tunnel: <TUNNEL_ID>
credentials-file: C:\Users\village-svc\.cloudflared\<TUNNEL_ID>.json
ingress:
  - hostname: api-dev.<你的测试域>.xyz
    service: http://127.0.0.1:8000
    originRequest:
      connectTimeout: 30s
      noTLSVerify: true          # 回源为 http
  - service: http_status:404
```

```powershell
cloudflared service install
Get-Service cloudflared
# 验证：访问 https://api-dev.xxx.xyz/healthz
```

**必须注意的 3 个限制**

1. **单请求 100MB 上限**：所以分片上传是硬需求。图片 ≤ 20MB 没问题；视频 500MB 会被切成 5MB 一片，每片独立请求，天然规避限制。
2. **WebSocket 空闲 100s 断开**：客户端心跳 25s 一次，已在设计内；断线重连带 `last_seq` 补消息。
3. **WS 必须用 `wss://`**，前端 `VITE_WS_BASE_URL` 随环境切换。

**切到正式域名时只需改 3 处**：Vercel 环境变量 `VITE_API_BASE_URL` / `VITE_WS_BASE_URL`、后端 `.env` 的 `CORS_ORIGINS`、DNS。不涉及代码改动。

### 2.6 阶段 C：换到已备案域名

```
1. 备案通过 → 在 Vercel 项目 Settings → Domains 添加 village.example.com，按提示配置 CNAME
2. 后端 .env：PUBLIC_BASE_URL=https://api.example.com，CORS_ORIGINS=https://village.example.com
3. Caddy 改用正式域名（见 3.5），自动签发证书，停掉 cloudflared 服务
4. Vercel 环境变量更新后 Redeploy
5. 全站回归：登录、上传、聊天 WS、PWA 安装
```

> 阶段 A/B 期间**不要用未备案域名对外大规模宣传**（尤其是贴到村里），避免被拦截或影响备案主体。内测用微信群直接发链接即可。

### 2.7 国内访问加速（阶段 D，可选）

若长辈反馈“打不开、转圈”：
1. 前端构建产物额外部署一份到 Windows Server（Caddy 托管 `D:\village-data\web-dist`），用已备案域名的子域 `www.example.com`；
2. 或在 Vercel 绑定已备案二级域名 + 国内 CDN 回源（需服务商支持）。

## 3. 后端部署（Windows Server，无 Docker）

### 3.1 目录规划

```
D:\village\
├── app\                     # 代码（git clone）
├── venv\                    # Python 虚拟环境
├── .env                     # 生产配置（仅管理员可读）
├── logs\                    # uvicorn/caddy 日志
└── tools\                   # ffmpeg.exe, nssm.exe, caddy.exe

D:\village-data\             # 数据盘（见 02 文档 6.1）
```

### 3.2 安装步骤

```powershell
# ---- 1. 基础环境 ----
# 安装 Python 3.12（勾选 Add to PATH）、Git、NSSM、Caddy
# ffmpeg 静态构建解压到 D:\village\tools\ffmpeg\

# ---- 2. 拉代码 & 虚拟环境 ----
cd D:\village
git clone https://github.com/yourname/village-memory.git app
cd app\api
python -m venv D:\village\venv
D:\village\venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -e .

# ---- 3. 配置 ----
Copy-Item .env.example D:\village\.env
notepad D:\village\.env     # 填写 SECRET_KEY / DATABASE_URL / 管理员账号

# ---- 4. 建库 ----
alembic upgrade head
python -m app.scripts.seed        # 写入初始 site_settings + 超级管理员

# ---- 5. 冒烟测试（前台运行）----
uvicorn app.main:app --host 127.0.0.1 --port 8000
# 浏览器访问 http://127.0.0.1:8000/healthz 应返回 ok
```

```ini

SECRET_KEY=<openssl rand -hex 32 生成>

# 迁 PG 后改为：
```

> `SECRET_KEY` 泄露 = 任何人可伪造 token。生成后只存在服务器与本机密码管理器中。

### 3.4 注册为 Windows 服务（NSSM）

```powershell
$nssm = "D:\village\tools\nssm\nssm.exe"

& $nssm install VillageAPI "D:\village\venv\Scripts\python.exe" `
    "-m uvicorn app.main:app --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1 --no-server-header"

& $nssm set VillageAPI AppDirectory "D:\village\app\api"
& $nssm set VillageAPI AppEnvironmentExtra "APP_ENV=production"
& $nssm set VillageAPI AppStdout "D:\village\logs\api-out.log"
& $nssm set VillageAPI AppStderr "D:\village\logs\api-err.log"
& $nssm set VillageAPI AppRotateFiles 1
& $nssm set VillageAPI AppRotateBytes 10485760
& $nssm set VillageAPI AppExit Default Restart
& $nssm set VillageAPI AppRestartDelay 5000
& $nssm set VillageAPI Start SERVICE_AUTO_START
& $nssm set VillageAPI ObjectName ".\village-svc" "<服务账号密码>"   # 专用低权限账号

Start-Service VillageAPI
Get-Service VillageAPI
```

**要点**
- `--host 127.0.0.1`：只监听本机，公网访问必须经过 Caddy。
- **单 worker**：WebSocket 连接管理在进程内存，多 worker 会导致广播错乱。
- 若 pydantic/uvloop 在 Windows 报错：不安装 `uvloop`、不安装 `uvicorn[standard]` 中的 winloop 相关依赖，纯 `asyncio` 即可。

### 3.5 Caddy 反向代理

`D:\village\tools\caddy\Caddyfile`

```caddy
{
    email you@example.com
    admin off
}

api.example.com {
    encode zstd gzip

    # 派生媒体：静态直出，长缓存
    handle_path /media/derived/* {
        root * D:/village-data/derived
        header Cache-Control "public, max-age=31536000, immutable"
        file_server
    }

    # 后端 API + WebSocket（Caddy 自动处理 Upgrade）
    handle /api/* {
        reverse_proxy 127.0.0.1:8000 {
            header_up X-Real-IP {remote_host}
            flush_interval -1        # 必需：让 WS 帧实时下发
        }
    }
    handle /ws* {
        reverse_proxy 127.0.0.1:8000 {
            flush_interval -1
        }
    }

    handle /healthz {
        reverse_proxy 127.0.0.1:8000
    }

    # 私有媒体与附件走 FastAPI 鉴权，不在此直出
    handle {
        reverse_proxy 127.0.0.1:8000
    }

    header {
        Strict-Transport-Security "max-age=31536000; includeSubDomains"
        X-Content-Type-Options "nosniff"
        -Server
    }

    log {
        output file D:/village/logs/caddy-api.log {
            roll_size 20mb
            roll_keep 10
        }
        format json
    }
}
```

再安装 Caddy 服务：
```powershell
caddy.exe validate --config D:\village\tools\caddy\Caddyfile
& $nssm install Caddy "D:\village\tools\caddy\caddy.exe" "run --config D:\village\tools\caddy\Caddyfile"
& $nssm set Caddy AppDirectory "D:\village\tools\caddy"
Start-Service Caddy
```

> 首次启动需 80 端口可访问以完成 ACME 校验。若家庭宽带 80 被封锁，改用 DNS-01 挑战（`caddy-dns/alidns` 插件）。

### 3.6 防火墙与网络

```powershell
New-NetFirewallRule -DisplayName "HTTP"  -Direction Inbound -Protocol TCP -LocalPort 80  -Action Allow
New-NetFirewallRule -DisplayName "HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow
# 8000 不对公网开放（保持默认拒绝）
```

**路由器端口转发**：外网 80/443 → 内网服务器 80/443。若使用 IPv6，需同时放行 v6。

## 5. 备份与恢复

### 5.1 备份策略

| 内容 | 频率 | 方式 | 保留 |
| --- | --- | --- | --- |
| SQLite 数据库 | 每日 03:00 | `VACUUM INTO` 一致性快照 | 30 天 |
| 上传媒体 | 每日增量 | `robocopy /MIR` 到备份盘 | 镜像 |
| 完整打包 | 每周日 | 7z 分卷压缩 | 8 周 |
| 异地 | 每周 | 上传网盘（人工或 rclone） | 8 周 |

### 5.2 `deploy\windows\backup.ps1`

```powershell
$ErrorActionPreference = "Stop"
$ts      = Get-Date -Format "yyyyMMdd-HHmm"
$data    = "D:\village-data"
$backup  = "E:\village-backup"          # 另一块物理盘
$keep    = 30

New-Item -ItemType Directory -Force -Path "$backup\db","$backup\weekly" | Out-Null

# 1) 数据库一致性快照（比直接复制 db 文件安全）
$py = "D:\village\venv\Scripts\python.exe"
& $py -c @"
import sqlite3
src = sqlite3.connect(r'D:/village-data/village.db')
dst = sqlite3.connect(r'$backup/db/village-$ts.db')
src.backup(dst); dst.close(); src.close()
"@

# 2) 媒体增量镜像
robocopy "$data\uploads"     "$backup\uploads"     /MIR /R:2 /W:5 /NFL /NDL /NP /LOG+:"$backup\robocopy.log"
robocopy "$data\derived"     "$backup\derived"     /MIR /R:2 /W:5 /NFL /NDL /NP /LOG+:"$backup\robocopy.log"
robocopy "$data\videos"      "$backup\videos"      /MIR /R:2 /W:5 /NFL /NDL /NP /LOG+:"$backup\robocopy.log"
robocopy "$data\attachments" "$backup\attachments" /MIR /R:2 /W:5 /NFL /NDL /NP /LOG+:"$backup\robocopy.log"

# 3) 周日打包
if ((Get-Date).DayOfWeek -eq "Sunday") {
  & "C:\Program Files\7-Zip\7z.exe" a -t7z -mx=5 -v2g "$backup\weekly\village-$ts.7z" "$backup\db" "$backup\uploads" "$backup\derived"
}

# 4) 清理旧快照
Get-ChildItem "$backup\db\village-*.db" |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-$keep) } | Remove-Item -Force

Write-EventLog -LogName Application -Source "VillageBackup" -EventId 1001 -EntryType Information -Message "backup ok $ts"
```

注册计划任务：
```powershell
schtasks /Create /TN "VillageBackup" /TR "powershell -NoProfile -ExecutionPolicy Bypass -File D:\village\app\deploy\windows\backup.ps1" /SC DAILY /ST 03:00 /RU SYSTEM /F
```

### 5.3 恢复演练（每季度一次）

```
1. 停 VillageAPI 服务
2. 把 backup\db\village-最新.db 复制为 D:\village-data\village.db
3. robocopy 反向恢复媒体目录
4. 启动服务，检查 /healthz 与首页
5. 记录恢复耗时（目标 ≤ 4h）
```

**不要只备份不验证**：每季度打开一个 zip 确认能解压、能起服务。这是本项目最重要的一条运维纪律。

### 6.3 监控与告警

| 项 | 方式 | 阈值 |

> 简单告警通道：用 Server 酱 / 企业微信机器人 Webhook，10 行代码即可接。

## 7. 安全加固

1. **专用服务账号**：`village-svc` 仅对 `D:\village` 与 `D:\village-data` 有读写权限，非 Administrator。
2. **关闭不必要端口**，RDP 改非默认端口 + 仅允许指定 IP，或改用 VPN/Tailscale 管理。
3. **Windows 更新**开启自动安装（每月维护窗口重启）。
4. **防御暴力破解**：RDP 与后台登录均失败锁定；可选安装 fail2ban 等价工具。
5. **`docs` 与 `/openapi.json`**：生产环境关闭（`docs_url=None`）或加 Basic Auth。
6. **上传目录不可执行**：`D:\village-data` 不设 IIS，Caddy 只按 `file_server` 返回，不解析脚本。
7. **审计日志保留 180 天**，管理员所有写操作留痕。
8. **密钥管理**：`.env` 仅 Administrators 与 `village-svc` 可读：
   ```powershell
   icacls "D:\village\.env" /inheritance:r /grant "Administrators:F" /grant "village-svc:R"
   ```

## 9. 域名、备案与法律提示

### 9.1 四阶段上线路径

| 阶段 | 前端 | 后端 | 域名 | 备案 |
| --- | --- | --- | --- | --- |
| A · 内测 | Vercel 默认域名 | Cloudflare Tunnel | 平台二级域名 | 不需 |
| B · 试运行 | Vercel（+ Pages 备用） | Cloudflare Tunnel | 平台二级域名 | 申请中 |
| C · 正式 | Vercel 绑自有域名 | Caddy 直连 + 自动 HTTPS | 已备案域名 | 已完成 |
| D · 加速 | 国内 CDN / 同机房副本 | 不变 | 不变 | 已完成 |

切换步骤见 2.5 与 2.6；全程只需改环境变量与 DNS。

### 9.2 备案要点

- 备案要求：域名已实名认证 ≥ 3 天；服务器需为大陆服务商（部分地区要求备案服务码/云服务器）。
- 流程：服务商提交 → 初核 → 管局审核（7–20 工作日）→ 公安备案（30 日内）。
- 备案主体建议用**个人**（纪念站，无经营性内容），网站名称不要含“村委”“协会”等容易要求单位资质的词；名称可用“老村记忆”类中性表述（以管局实际要求为准）。
- 备案期间 80/443 不可对自有域名开放服务，但**阶段 A/B 用平台域名不受影响**。
- 备案通过后页脚展示备案号（`site.icp` 配置项），并链接到 `beian.miit.gov.cn`。

### 9.3 其他合规提示

- 上传内容涉及他人肖像，建议在“关于本站”写明用途与“申请下架”联系方式。
- 已故村民信息录入建议征得直系家属同意。
- 建议为域名、Vercel 账号、服务器续费设置**日历提醒**（提前 60 天），避免项目因到期而消失。
